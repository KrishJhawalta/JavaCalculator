# 🧮 Java Console Calculator

A simple **console-based calculator** built in **Java** using the fundamentals of **Object-Oriented Programming (OOP)**. This project performs basic arithmetic operations through a menu-driven interface and is designed as a beginner-friendly Java application.

---

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🟰 Modulus
* 🔄 Menu-driven interface
* 🔁 Continuous execution until the user exits
* ⚠️ Division by zero handling

---

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (Classes, Objects, Methods)
* Scanner Class
* Switch-Case
* While Loop

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/java-calculator.git
```

### 2. Open the project

```bash
cd java-calculator
```

### 3. Compile the program

```bash
javac Calculator.java
```

### 4. Run the program

```bash
java Calculator
```
